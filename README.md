# Lab 6 and Lab 7 — Mobile Data Plan

This project contains the assigned mobile data plan exercises for SRN PES2UG24AM205.

- **Lab 6:** line and branch coverage tests for overage charges, recharge eligibility, and plan validity.
- **Lab 7:** Hypothesis fuzz tests for plan parsing, usage averages, and payable bills, with the original processor preserved for reproducing failures and a hardened version for final tests.

## Layout

```text
.
├── requirements.txt
├── Lab 6/
│   ├── mobile_data_plan.py
│   ├── CodeCoverageTest_PES2UG24AM205_application.py
│   └── BranchCoverageTest_PES2UG24AM205_application.py
├── Lab 7/
│   ├── mobile_data_plan.py
│   ├── mobile_data_plan_before.py
│   ├── fuzz_before_demo.py
│   ├── test_mobile_data_plan.py
│   └── BUG_FINDINGS.md
└── evidence/
    ├── README.md
    ├── Lab6/
    └── Lab7/
```

See each lab folder's README for commands. The assignment handouts require terminal screenshots; `evidence/README.md` lists the screenshots to capture. Coverage and Hypothesis reports must be generated by running the commands after installing the dependencies.
